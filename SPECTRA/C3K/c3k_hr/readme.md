# C3K_HR

These are the C3K_HR spectra for use in FSPS.  They have been downsampled from
the full R=300,000 C3K v2.3, vt10_allfal resolution between 3000 and 2.5 micron,
and using the ATLAS12 flux files (based on opacity binning) outside that range.
These use the native C3K logg-logt grid. The spectra are critically sampled with
the resolution given in the table below.

Due to file size constraints, only the solar-scaled (afe+0.0) models are
provided here. Contact mp2246@cam.ac.uk to obtain the $\alpha$-enhanced C3K_HR
libraries.

| wave_low (AA) | wave_high (AA) | R (lambda/FWHM) |
|---------------|----------------|-----------------|
| 100           | 1000           | 200             |
| 1000          | 3000           | 500             |
| 3001          | 10000          | 3000            |
| 10000         | 25000          | 500             |
| 25000         | 100000000      | 500             |
